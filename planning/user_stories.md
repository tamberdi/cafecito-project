# User Stories
 
## New user
 
1. As a new user, I want to create a profile with my native language and the language(s) I'm learning, so that I can be matched with compatible partners.
2. As a new user, I want to specify my proficiency level for each language, so that I'm matched with partners at an appropriate level.
3. As a new user, I want to set my timezone and availability, so that potential partners know when I'm free to practice.
4. As a new user, I want to browse a list of potential partners filtered by language pair, so that I can find someone relevant to practice with.
5. As a new user, I want to send a partnership request to another user, so that we can start practicing together.
6. As a new user, I want to see a clear error message if I try to create a profile without selecting a language, so that I know what I need to fix.
## Active learner
 
7. As an active learner, I want to view all my active and past partnerships in one place, so that I can keep track of who I'm practicing with.
8. As an active learner, I want to log a practice session quickly using a modal, so that I can record it right after it happens without losing my place in the app.
9. As an active learner, I want to see my current practice streak, so that I stay motivated to keep practicing consistently.
10. As an active learner, I want to add notes to a logged session, so that I can remember what we covered and what to focus on next time.
11. As an active learner, I want to be prevented from logging a session with an unrealistic duration (like 0 minutes), so that my practice data stays accurate.
12. As an active learner, I want to end a partnership that's no longer active, so that my partnerships list reflects who I'm currently practicing with.
13. As an active learner, I want to filter my logged sessions by partner or date range, so that I can review my practice history for a specific language or time period.
14. As an active learner, I want to tag a session with the topics or skills we practiced, so that I can review what I've covered and identify gaps.
15. As an active learner, I want to filter my session history by topic, so that I can see how much I've practiced a specific skill (e.g., past tense).
